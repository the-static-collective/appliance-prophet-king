# appliance-prophet-king

> the vision: a toaster/air-fryer hybrid moving one step toward a food synthesizer.

This repository is a workshop for strange-but-buildable countertop appliances.

## Build rule

`main` is the stable landing floor. Working generations live on numbered version branches so a useful phase can stay inspectable even after the next mutation begins.

Current experimental line: **NuToaster** — removable angled cooking troughs, surrounding electric heat, and optional spring compression.

See the numbered branches for active prototype slices.
