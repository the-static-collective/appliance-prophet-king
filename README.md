# appliance-prophet-king

> the vision: a toaster/air-fryer hybrid moving one step toward a food synthesizer.

This repository is a workshop for strange-but-buildable countertop appliances.

## Build rule

`main` is the stable landing floor. Working generations live on numbered version branches so a useful phase can stay inspectable even after the next mutation begins.

## 001 — NuToaster prototype

**Current slice:** [prototype-001/README.md](./prototype-001/README.md)

**Schematic:** [prototype-001/nutoaster-001.svg](./prototype-001/nutoaster-001.svg)

NuToaster is a toaster-shaped dual-bay cooker built around four ideas:

- two parallel ~45° removable steel cooking troughs;
- fixed electric heating structure outside and between the troughs;
- trough walls that can move inward on guided springs;
- **compression as a setting** — OFF / LOW / MEDIUM / HIGH — rather than something every food must endure.

The practical question for this branch is small:

> Can removable containment + surrounding heat + optional pressure create a genuinely useful countertop cooking primitive?

The next physical move is deliberately non-electrical: build one full-size cold trough and measure the geometry, removal path, and useful wall travel.
